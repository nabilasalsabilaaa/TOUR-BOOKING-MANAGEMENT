<h1 align="center">🌍 TourBooking System</h1>
<p align="center">A modern, responsive tour booking platform built with Laravel, TailwindCSS, and MySQL.</p>

<br>

---

<h2>✨ Overview</h2>

TourBooking System adalah aplikasi pemesanan tour yang dirancang untuk memberikan pengalaman user yang modern, cepat, dan mudah digunakan.  
Aplikasi ini mendukung dua role utama:

- **Customer** → mencari tour, booking jadwal, melihat riwayat pemesanan.
- **Admin** → mengelola tour, jadwal, dan memonitor seluruh booking.

Aplikasi ini dibangun menggunakan:

- **Laravel 10+**
- **TailwindCSS**
- **MySQL / MariaDB**
- **Blade Templates**
- **FontAwesome**
- **Vite**

---

<br>

<h2>🚀 Features</h2>

### 🎫 Customer
- Melihat daftar tour
- Booking tour dengan memilih tanggal & jumlah tamu
- Melihat status booking (Pending, Confirmed, Cancelled)
- Melihat booking detail lengkap
- Riwayat booking
- Notifikasi (opsional WhatsApp)

### 🛠 Admin
- CRUD Tour
- CRUD Jadwal Tour (Tour Schedules)
- Melihat seluruh booking customer
- Dashboard statistik (jumlah booking, revenue, pending approval)
- Upcoming tours tracking

### 🎨 UI/UX
- Fully responsive
- Custom Tailwind Theme
- Card hover effects
- Status badges
- Elegant dashboard layout
